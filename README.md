# WaterInBangkok — แผนที่เสี่ยงน้ำท่วม กทม. + ปริมณฑล

เว็บ Next.js แสดงความเสี่ยงน้ำท่วมราย **79 เขต/อำเภอ** (กรุงเทพฯ นนทบุรี ปทุมธานี สมุทรปราการ สมุทรสาคร นครปฐม)
แบ่ง 4 โซน: **ปกติ / เฝ้าระวัง / เสี่ยงท่วม / เสี่ยงท่วมหนัก**

## เริ่มใช้งาน
```bash
npm install
npm run dev        # http://localhost:3000
# ดูตัวอย่างด้วยข้อมูลจำลอง: http://localhost:3000/?demo=1
npm test           # ทดสอบสูตรคำนวณคะแนน
npm run build && npm start
```
Deploy: push ขึ้น GitHub แล้ว import เข้า Vercel ได้ทันที (ไม่ต้องตั้ง env / API key)

## แหล่งข้อมูล (ฟรี ไม่ต้องใช้ key)
| แหล่ง | ใช้ทำอะไร | Endpoint |
|---|---|---|
| Open-Meteo Forecast | ฝนรายชั่วโมง ย้อนหลัง 72 ชม. + พยากรณ์ 24 ชม. ที่จุดกึ่งกลางทุกเขต | `api.open-meteo.com/v1/forecast` |
| Open-Meteo Flood (GloFAS) | น้ำท่าเจ้าพระยา (นนทบุรี) และท่าจีน (นครชัยศรี) เทียบค่าเฉลี่ย 60 วัน | `flood-api.open-meteo.com/v1/flood` |
| ThaiWater (สสน.) | ระดับน้ำ/สถานการณ์สถานีโทรมาตร (ล้นตลิ่ง, % ความจุ) | `api-v3.thaiwater.net/.../waterlevel_load` |
| OpenGISData-Thailand | ขอบเขตอำเภอ/เขต (simplified) | `public/data/districts.geojson` |

ดึงฝั่ง server ที่ `app/api/flood/route.ts` แคช 30 นาที — ถ้าแหล่งใดล่ม หน้าเว็บยังทำงานต่อด้วยแหล่งที่เหลือ และแสดงสถานะแต่ละแหล่ง

## สูตรคะแนน (`lib/scoring.ts`)
- ฝน = 0.45·(ฝน24ชม./90) + 0.20·(ฝน72ชม./180) + 0.35·(พยากรณ์24ชม./90)  (90 มม. = ฝนหนักมาก ตามเกณฑ์กรมอุตุฯ)
- ระดับน้ำ = ล้นตลิ่ง/≥100% → 1.0, น้ำมาก → 0.6, 80–100% → 0.3–0.8
- แม่น้ำ = (น้ำท่าสูงสุด 3 วัน ÷ เฉลี่ย 60 วัน − 1) / 1.5 (เฉพาะเขตริมแม่น้ำ)
- hazard = ถ่วง 55/30/15 (ตัดปัจจัยที่ไม่มีข้อมูลแล้วถ่วงใหม่) × ความเปราะบางพื้นที่ (0.35/0.55/0.8)
- ระดับ: 0–14 ปกติ · 15–34 เฝ้าระวัง · 35–54 เสี่ยงท่วม · 55+ เสี่ยงท่วมหนัก · สถานีล้นตลิ่ง → อย่างน้อย "เสี่ยงท่วม"

ค่าความเปราะบางพื้นที่เป็น **ค่าประมาณ** (แก้ได้ที่ field `base` ใน `public/data/districts.geojson` และ `lib/data/districts.json`)
